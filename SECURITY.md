# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 0.1.x | Yes |

## Reporting a Vulnerability

If you discover a security vulnerability in `parley` or any component of the TideOS Eval Kit, please do not open a public issue.

Email security reports directly to: `security@techtideai.io`

Include:
1. Detailed description of the vulnerability.
2. Reproduction steps and minimal sample suite or transcript.
3. Impact assessment.

We acknowledge reports within 24 hours and issue fixes promptly.
